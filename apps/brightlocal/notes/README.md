# Page notes

One markdown file per route, rendered inside the prototype (Cmd+K, "Page
notes", or Cmd+.). The file name is the route with slashes turned into
dashes: `/reviews/tracker` reads `reviews-tracker.md`, `/` reads
`home.md`. A route with no file shows this one.

Write whatever helps a reviewer: what the page is for, what is proposed
and why, what is placeholder, open questions. Plain markdown, GitHub
flavoured (tables and task lists work).
