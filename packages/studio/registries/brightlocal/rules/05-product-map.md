BrightLocal product map — how to interpret lazy vertical prompts.
When a request names a product vertical ("the hub page for Citations", "rankings page", "reviews dashboard"), do NOT invent navigation: use the standard app shell (SidebarProvider > GlobalLayout > GlobalLayoutSidebar > Sidebar with Header/Content/Footer, footer = SidebarAccountDropdown), set isActive on that vertical's nav item, and title the page header for the vertical. Location nav items, in order: Location Summary, AI Insights, Rankings, Local Search Grid, Citations, GBP, Reputation & Reviews.
Responsive shell: the sidebar hides below lg (the live platform's behaviour). Every app-shell screen must include a mobile top bar as the FIRST child of GlobalLayoutContent: <header className="flex items-center gap-2 px-3 py-2 lg:hidden"><SidebarTrigger dataHook="mobile-sidebar-trigger" className="size-11"><Menu className="size-5" /></SidebarTrigger><Logo className="h-6" dataHook="mobile-logo" /></header>. The Menu (three-line hamburger, from @brightlocal/icons) matches the live platform; the size-11 (44px) className is the minimum touch target and the size-5 glyph matches the sidebar nav icons. No border-b — the live platform's mobile bar has no dividing line. SidebarTrigger opens the design system's built-in mobile sheet — never hand-roll a drawer.
Demo persona: the logged-in user in every screen is Andy Smith (andy@acmecorp.com, avatar initials AS) — use exactly this in the SidebarAccountDropdown and anywhere a signed-in user appears.
Sidebar nav icons: lucide icons from @brightlocal/icons at 20px (className="size-5", default strokeWidth) — inside sidebar navigation this overrides the general "16px" icon rule. (Deliberate deviation: the live platform ships 24px/strokeWidth 1.33 here, which contradicts its own docs and reads oversized; 20px is our curated middle.) Icon pairings: Your Locations=House, Location Summary=LayoutDashboard, AI Insights=Sparkles, Rankings=TrendingUp, Local Search Grid=Grid3x3, Citations=Link, GBP=Store, Reputation & Reviews=Star, Location Manager=Building, White-label=Globe.
Hub-page conventions per vertical (a hub = score/stat summary row + one primary work surface + one CTA):
- Citations — citations-found score (e.g. 53/60), listings sync status, directory table (directory name, listing status, NAP accuracy), CTA "Build Citations".
- Rankings — average ranking position, keywords in top 3, search visibility %, tracked-keywords table, CTA "Run New Audit".
- Local Search Grid — geo-grid map as the primary surface, keyword selector, competitor comparison beside it.
- GBP — profile-completeness score, field-level audit checklist, sync status.
- Reputation & Reviews — average rating, review velocity, per-site breakdown (Google, Facebook, Yelp), reply queue.
- Location Summary — the overview dashboard: visibility score, rating, citations and actions-required stat cards.
