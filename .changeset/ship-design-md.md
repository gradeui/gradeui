Make the package self-describing for any consumer (any agent, not just Grade Studio).

- Ship a generated **`DESIGN.md`** — one comprehensive design spec assembled from the
  package's own sidecars: foundations (themes, colour scopes, expressive accents,
  typography, spacing & layout) + every component sidecar. Generated by
  `scripts/generate-design.mjs` (wired into `prebuild`), so it can never drift from the code.
- Ship **`AGENTS.md`** (the "read me first" entry point + the Section→Container scaffold
  rule) and **`DESIGN.index.md`** (a cheap one-line-per-component scan for retrieval).
- Add new **foundation docs** (`foundations/*.md`) — the rules that aren't components.
- Advertise them via `exports` (`./DESIGN.md`, `./DESIGN.index.md`, `./AGENTS.md`,
  `./foundations/*`) and include them in `files` so they reach npm consumers.
- Add `scripts/verify-portability.mjs` + `pnpm verify:portability` — packs the real
  tarball and asserts every consumer-facing artifact ships (and that DESIGN.md isn't stale).
